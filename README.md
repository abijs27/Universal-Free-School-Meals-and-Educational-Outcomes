# Universal-Free-School-Meals-and-Educational-Outcomes

This repository contains an analysis of universal free school meals and educational outcomes from the 2014-2015 to 2018-2019 academic years for Pennsylvania schools. 

The final combined dataset for analysis is titled school_df.csv. (Note: I recommend against downloading and re-uploading this file for analysis as many school identification numbers start with 0s, and 0s can be stripped during the download/upload process. Please run the Data Cleaning portion of the Universal_Free_School_Meals_and_Educational_Outcomes.ipynb Jupyter notebook to import the individual csv files in this repository to create the school_df DataFrame.)
